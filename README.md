# Парадиз (Paradiz)

Репозиторий проекта «Парадиз».

## О проекте

Сайт **PARADIZ · decorative materials** — производителя декоративных покрытий с фактурой натурального камня: жидкий камень из тёртого мрамора и травертина (**Travertino**, **Marble**) и **Microcement**. Производство в Москве, работа по всей России и СНГ.

Направления: продажа материалов, отделка интерьера под ключ, покрытие мебели камнем, интерьерные скалы, обучение мастеров.

Подробности — [docs/project.md](docs/project.md), презентации — [docs/presentations/](docs/presentations/).

Текущая версия сайта: https://site-kgxfldwu.devinapps.com/
